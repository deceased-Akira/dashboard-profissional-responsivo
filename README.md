# Dashboard Profissional Responsivo

Página web de apresentação profissional e acadêmica de **Ana Júlia Pantoja Chagas**, desenvolvida na Atividade Prática IV da disciplina Desenvolvimento Front-End (Engenharia de Software, Centro Universitário Fametro).

## Tecnologias utilizadas
- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `address`, `footer`)
- CSS3 (variáveis, sombras, bordas, estados de hover e foco)
- Flexbox no cabeçalho, menu, cards, contato e rodapé
- Media Queries para desktop, tablet e smartphone

## Principais funcionalidades
- Menu de navegação com links para cada seção
- Seções: Sobre, Formação, Experiência, Competências, Projetos e Contato
- Layout que se adapta a diferentes tamanhos de tela
- HTML e CSS em arquivos separados
